# Design plan reviewer rubric

Portability: `adapter-required`

## Purpose

Review UI/design plans for user experience quality, consistency, and AI-slop risk before implementation.

## Dimensions

Score relevant dimensions 0-10 and explain material gaps:

- user goal clarity.
- information architecture.
- interaction model.
- visual hierarchy.
- accessibility.
- responsiveness.
- design-system consistency.
- implementation feasibility.

## Output

- Summary verdict.
- Scores.
- Must-fix design risks.
- Suggestions.
- Open questions.
