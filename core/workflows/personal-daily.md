# Personal daily workflow template

Portability: `personal-template`

## Purpose

Capture start-of-day and end-of-day state across a configurable set of repositories.

## Required parameters before sharing

- Repository list.
- Daily note directory.
- Issue tracker source.
- PR source.
- Workday calendar assumptions.

## Rule

Do not publish a personal daily workflow as a general workshop skill until all organization-specific repository names and storage paths are parameterized.
