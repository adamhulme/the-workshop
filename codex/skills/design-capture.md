# Codex skill: design-capture

Shared contract: `core/workflows/design-capture.md`

## Use when

The user wants an existing application's design system documented.

## Codex behavior

1. Inspect frontend code, styles, tokens, components, and screenshots if available.
2. Identify repeated patterns and inconsistencies.
3. Propose a design-system summary.
4. Ask before writing or replacing `DESIGN.md`.
5. Include unresolved inconsistencies and recommended next steps.
