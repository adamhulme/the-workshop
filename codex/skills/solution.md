# Codex skill: solution

Shared contract: `core/workflows/solution.md`

## Use when

The user wants to capture a decision, implementation progress, shipped outcome, or reusable lesson.

## Codex behavior

1. Resolve or derive a safe slug.
2. Read any matching plan, PR notes, commits, and existing solution doc.
3. Create or update `docs/solutions/<slug>.md`.
4. Move the lifecycle forward only when evidence supports it.
5. If the outcome produced a durable lesson, propose adding it to shared project instructions.

## Output expectation

Summarize the file updated, lifecycle state, and any follow-up or learned principle.
