# Codex skill: brainstorm

Shared contract: `core/workflows/artifact-conventions.md`

## Use when

The user wants multi-perspective ideation before choosing a direction.

## Codex behavior

1. Read matching `docs/research/` material first.
2. Explore the topic through user, operations, scope, and risk lenses.
3. Surface tensions rather than collapsing them.
4. Save to `docs/brainstorms/<slug>.md` when asked or when the workflow calls for persistence.
